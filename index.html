Música

Existe um espaço especial para música japonesa, principalmente J-Pop, mas provavelmente nada ocupa tanto espaço quanto Vocaloid. Vocaloid é uma tecnologia de síntese vocal que permite produzir músicas utilizando vozes virtuais. O que mais gosto nisso é justamente a liberdade criativa: diferentes produtores conseguem pegar as mesmas ferramentas e transformá-las em músicas com estilos, histórias e identidades completamente diferentes. Entre os meus produtores favoritos estão Inabakumori, Kikuo e Iyowa.

Moda e estética

Adoro a possibilidade de me identificar com uma estética e transformar isso em uma forma de expressão. Minha favorita é, sem dúvida, o estilo ouji (inclusive, ele foi uma das principais inspirações para a identidade visual deste portfólio). Também gosto muito de moda e de conhecer diferentes subculturas e estilos. Acho interessante como roupas, acessórios e estética podem funcionar quase como uma linguagem própria, permitindo que cada pessoa construa e expresse sua identidade de uma maneira diferente.

RPG em Java

Um jogo de RPG desenvolvido em Java para a disciplina de Programação Orientada a Objetos (POO) na faculdade. O projeto permite personalizar seu personagem e escolher entre três classes: Guerreiro, Mago e Clérigo. Durante o jogo, é possível enfrentar inimigos através de um sistema de batalhas aleatórias, evoluir de nível e acumular moedas. O projeto também conta com uma loja, onde é possível adquirir itens para aumentar atributos como vida e dano.

Menu de Jogos em Java

Um menu de jogos desenvolvido para a disciplina de POO em Java no qual é possível escolher entre três jogos de tabuleiro: Xadrez, Jogo da Velha e Cara a Cara. Além de reunir os jogos em um único programa, o projeto possui um sistema que tenta adivinhar quais opções de jogo o usuário escolheu com base nas respostas fornecidas durante a interação.

Calculadora Fitness em Python

Uma calculadora desenvolvida em Python para a disciplina de Raciocínio Algorítmico. O programa reúne diferentes cálculos e informações relacionadas à rotina de exercícios, incluindo IMC, meta diária de hidratação, opções de treino, Taxa Metabólica Basal (TMB), gasto calórico total, objetivo e meta diária.

IrFlow

Trabalho em grupo desenvolvido para a disciplina de Experiência Criativa. O principal objetivo do IrFlow é facilitar a organização de documentos pessoais relacionados ao Imposto de Renda. Experimento #1

Um dos experimentos que fiz foi criar meu próprio modelo VTuber, juntando algumas coisas que gosto bastante: desenho, criação de personagens e tecnologia. VTubers são criadores de conteúdo que utilizam um avatar virtual animado para se representar, geralmente com movimentos e expressões que acompanham a pessoa em tempo real. Nesse projeto, pude experimentar um pouco desse processo e transformar um personagem que criei em algo que pudesse ganhar vida de uma maneira diferente.

Para criar o modelo, utilizei o Live2D Cubism, um programa voltado para transformar ilustrações em personagens 2D animados. Ele permite separar e organizar as partes de um desenho e configurar movimentos, expressões e deformações, fazendo com que o personagem consiga se movimentar de forma mais natural.

Experimento #2

Outro tipo de experimento que gosto bastante de fazer são animações em tweening. Primeiro crio o desenho e depois levo ele para o Alight Motion, onde trabalho os movimentos e transições. Gosto principalmente de combinar essas animações com músicas, tentando fazer com que os movimentos acompanhem o ritmo e transmitam a personalidade do desenho.

O que mais gosto de fazer é o lip sync, sincronizando a boca do personagem com a música. Mesmo sendo um processo trabalhoso, já que preciso ficar mudando o desenho da boca várias vezes, a satisfação de ver o resultado final é o que mais me motiva a continuar fazendo.

Esse foi bem trabalhoso, visto que tive que animar o lip sync de 2 personagens ao mesmo tempo.

Uma das primeiras animações que fiz, ainda estava aprendendo a mexer no Alight Motion.

O Alight Motion é um aplicativo de edição e animação que permite trabalhar com diferentes camadas, efeitos, movimentos e transições. Uma das ferramentas que mais utilizo é o sistema de keyframes, que permite definir posições e propriedades diferentes ao longo do tempo para criar movimentos. Gosto de explorar essas possibilidades principalmente para fazer animações em tweening e sincronizá-las com músicas.
